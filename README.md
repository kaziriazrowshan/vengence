# Kolkata 2050: Experience the City of Tomorrow 🌆

An immersive **WebXR Virtual Reality (VR)** simulation exploring Kolkata's urban resilience and sustainable metamorphosis in the year 2050. Designed for **Meta Quest 3S / Quest 3 / Quest 2** and modern desktop/mobile web browsers.

[![Deploy to GitHub Pages](https://github.com/actions/deploy-pages/actions/workflows/deploy.yml/badge.svg)](https://github.com/actions/deploy-pages)

---

## 🌟 Key Features

- **WebXR 6DoF Roomscale VR**: Full head tracking and hand controller interaction on Meta Quest 3S via Meta Quest Browser.
- **11 Climate & STEM Scenarios**:
  - Monsoon 2050 Flooding & Subterranean Sponge-City Inundation Defense
  - 44°C Extreme Heatwave with Bioclimatic Canopy & Misting Cooling Totems
  - Particulate Smog Inversion vs Photocatalytic Facade Filtration
  - Autonomous Multi-Tier Transit: Solar Tramway, Maglev Sky-Metro, and Automated Ferries
  - Nocturnal Cyber-Heritage Spectacle: Illuminated Howrah Bridge 2.0 & Hooghly River Reflections
  - Observation Sky-Deck Horizon Panorama
- **Interactive Holographic Beacons**: STEM engineering data kiosks with English and Bengali labels.
- **Synthesized Ambient Audio Engine**: Dynamic Web Audio soundscapes responding to weather, vehicles, and climate transitions.
- **Concept Art Exhibition Pavilions**: 3D in-world photo pavilions and gallery modal highlighting visionary architectural renders.
- **Comfort Locomotion**: Thumbstick smooth locomotion, snap turning, and trigger-based raycast teleportation.

## 🚀 Quick Deployment to GitHub Pages

### Automatic Deployment (GitHub Actions)
1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Kolkata 2050 WebXR Project"
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
   git push -u origin main
   ```
2. In GitHub repository **Settings** > **Pages**, set **Source** to **GitHub Actions**.
3. Your app will automatically build and deploy to:
   `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/`

### Manual Deployment
```bash
npm install
npm run deploy
```

## 🥽 Testing on Meta Quest 3S

1. Put on your Meta Quest 3S headset.
2. Open the **Meta Quest Browser**.
3. Type your GitHub Pages URL `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/`.
4. Click **ENTER QUEST 3S VR** (or **ENTER VR**).
5. Accept the WebXR permission prompt.

See [DEPLOY.md](./DEPLOY.md) for full controller mappings and troubleshooting.
